# v10.8.4 Push Race Fix

Sorunun kök nedeni:
Firebase oturumu, özellikle iPhone/PWA'da OneSignal SDK hazır olmadan geri yüklenebiliyordu.
Bu durumda `identifyOneSignal()` sessizce çıkıyor ve cihaz `necati` external ID'sine bağlanmıyordu.

Düzeltmeler:
- OneSignal başlatma işlemi tek Promise üzerinden yönetiliyor.
- Firebase auth, OneSignal hazır olana kadar bekliyor.
- OneSignal daha sonra hazır olursa mevcut kullanıcı otomatik bağlanıyor.
- Bildirim izni / push subscription oluştuktan sonra external ID tekrar kesin olarak atanıyor.
- Agresif sürekli opt-in döngüsü yok.
- Tanılama ekranı permission, optedIn, subscriptionId ve OneSignal ID gösteriyor.
