# Necati Cepte ❤️

İlk PWA prototipi.

## Yerelde çalıştırma
PWA özellikleri için dosyayı doğrudan çift tıklamak yerine yerel bir sunucu kullanın:

```bash
python -m http.server 8080
```

Sonra tarayıcıda `http://localhost:8080` adresini açın.

## Telefona kurma
Site HTTPS üzerinden yayınlandığında destekleyen tarayıcılarda “Ana ekrana ekle / Uygulamayı yükle” seçeneği görünür.
